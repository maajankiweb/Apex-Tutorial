# 🎓 Apex Tutorial Bettiah - Official Web Portal

> **Empowering Students through Quality Education & Digital Learning Resources**  
> Developed and maintained by **MaaJanki Web Tech**.

---

## 🌟 Overview

**Apex Tutorial Bettiah** is a state-of-the-art educational coaching portal built to provide students, parents, and educators with seamless access to course details, exam results, academic notices, study materials, and direct inquiry forms. Designed with high-performance web standards and modern aesthetics, the platform delivers an engaging user experience across desktop and mobile devices.

---

## ✨ Key Features

- **📚 Course Catalog & Fee Structure**: Detailed view of competitive exam preparation, board exams (Class 8–12), and specialized coaching modules.
- **🏆 Student Results & Wall of Fame**: Interactive showcases of top achievers and past examination performance.
- **📢 Real-Time Notices & Announcements**: Dynamic updates for exam schedules, holiday notices, and upcoming batch enrollments.
- **📑 Digital Study Resources**: Free and downloadable study materials, practice papers, and syllabus guides.
- **💬 Student Reviews & Testimonials**: Verifiable community feedback and student success stories.
- **📱 Mobile-First Responsive Design**: Optimized layouts for low-latency browsing on modern and legacy mobile networks.

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18.x or higher) and npm installed:

```bash
node -v
npm -v
```

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/maajankiweb/Apex-Tutorial.git
   cd Apex-Tutorial
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   npm run start
   ```
